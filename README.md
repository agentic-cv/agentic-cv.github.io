# Agentic Computer Vision: Hype or Ripe?

Website for the Agentic Computer Vision: Hype or Ripe? workshop, proposed for CVPR 2027.

The site is plain HTML and CSS with no build step.

- `index.html` holds all the content: introduction, tentative schedule, speakers, and organizers.
- `style.css` holds the styling.
- `images/` holds the organizer photos, taken from each organizer's own homepage. Put speaker photos here too. A comment in `index.html` shows how to fill a speaker placeholder.

To preview locally, open `index.html` in a browser.

To publish, enable GitHub Pages under Settings > Pages, with the source set to the `main` branch and the root folder.
